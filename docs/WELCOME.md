# Asistente de bienvenida

Se abre después del alta cuando no hay conexiones configuradas. Puedes abrirlo también en Dashboard o Ajustes → Proveedores. Las instalaciones que ya tienen accesos no se interrumpen automáticamente.

1. Selecciona las plataformas que utilizas. Esta versión conecta Coolify, Vercel, Cloudflare, Hostinger (un VPS elegido) y Supabase Cloud. Netlify, EasyPanel y otras plataformas admiten fichas manuales, sin conector API.
2. En cada paso pulsa **Obtener mi token**. Coolify ofrece instrucciones para crearlo en tu propio panel. Revisa los permisos antes de crear el acceso.
3. Guarda la conexión y pulsa **Consultar** para comprobarla. Vercel permite elegir cuenta/equipo; Hostinger requiere elegir un VPS. Usa tus cuentas y accesos.
4. Continúa y revisa el resumen. **Conexión comprobada** necesita una consulta reciente correcta; muestra el número de recursos, que puede ser cero para el alcance elegido. Una clave guardada sin consultar queda pendiente. Una consulta fallida o vencida necesita revisión. El inventario no comprueba transacciones internas de las aplicaciones.

**Configurar después**, cerrar con la X o Escape guardan selección y paso. Al reabrir, continúa donde quedaste. Las conexiones guardadas permanecen cifradas. Los campos que no guardaste debes completarlos otra vez. El progreso no contiene tokens, contraseñas ni borradores de accesos, ni se guarda en el navegador.

Puedes pasar a la siguiente plataforma sin configurarla. El resumen permite volver a las pendientes; finalizar exige comprobar las seleccionadas o posponer. Sin plataformas seleccionadas puedes empezar con tu espacio vacío. La demo tiene datos ficticios y no conecta tus cuentas.

Las consultas se ejecutan solo al pulsar los botones correspondientes. El asistente no activa observación periódica, IA, correo, respaldos, compras ni cambios en tu infraestructura. Esas opciones se configuran por separado. Seleccionar o quitar una plataforma en el asistente no borra sus accesos existentes.

El progreso pertenece a esta instalación: se conserva con su base de datos y las copias privadas de ConectadOS. Dos pestañas no pueden sobrescribir un paso más reciente sin actualizar. No lo transfieras subiendo archivos privados a GitHub.
